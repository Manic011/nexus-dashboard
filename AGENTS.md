# Nexus Dashboard

Develop and maintain Git locally. Build with `npm run build` and verify with `npm test`. Deploy only locally built artifacts to Ubuntu over verified SSH. Use Ubuntu for integration checks, preserve persistent state during deployments, and inspect service logs after deployment. Keep the repository private and keep credentials and deployment settings out of Git.

Treat documentation updates as part of each feature change. Follow the [documentation checklist](CONTRIBUTING.md#documentation-checklist). Update the affected guides, changelog, and roadmap in the same change. Record what was actually verified on Ubuntu.
