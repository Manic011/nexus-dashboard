# Nexus Dashboard

Develop and maintain Git locally. Build with `npm run build` and verify with `npm test`. Deploy only locally built artifacts to Ubuntu over verified SSH. Use Ubuntu as the integration environment and inspect service logs after deployment. Preserve persistent state during deployments and check the installed version before changes. Keep the repository private, keep credentials and deployment settings out of Git, and update the changelog and development status as capabilities change. See ARCHITECTURE.md and docs/INSTALL.md.
